# Контекст проекта Adal AI

Рабочий журнал части приложения: сайт, PWA, серверный слой, каналы, демо и
документация. Обновляется после каждого задания.

## О проекте

- **Проект:** Adal AI.
- **Конкурс:** «Адал қоғам», конкурс студенческих AI-проектов. Требования — в положении
  конкурса; их сверка с проектом — в [COMPETITION_REQUIREMENTS.md](COMPETITION_REQUIREMENTS.md).
- **Тематика (п. 4.1 положения):** интеллектуальный консультант и справочник-навигатор
  по внутренней политике и идеологической работе Казахстана. Помогает находить,
  систематизировать и понимать официальную информацию на казахском и русском языках.
- Это студенческий проект: не официальный государственный сервис и не универсальный помощник.

## Распределение работы

| Кто | Зона |
|---|---|
| Эмиль | Сайт и PWA, интерфейс чата, серверный слой и подключение ИИ, отображение ответов и источников, ошибки, сессии и история, Telegram и WhatsApp, deployment, GitHub, документация и подготовка защиты |
| Друг (ИИ-часть) | Функция `ask(message, history)` → `answer`, `sources`; база знаний и ответы |

## Задание 2. Сайт, чат и PWA (16.10.2026)

Этап выполнен раньше каркаса backend: ответы ИИ-части ещё собираются. Интерфейс
работает с **dev-mock API** во frontend (`frontend/dev/mockApi.ts`), который
реализует контракт `/api/*` из ARCHITECTURE.md §4.4. Работоспособность ИИ этим
**не подтверждается**: mock возвращает тестовые тексты.

### Что сделано

- `frontend/`: React 19.3 + TypeScript 6.0 + Vite 8.3, PWA (`vite-plugin-pwa` 1.3),
  `react-markdown` 10.1 + `remark-gfm` 4.0. Версии зафиксированы точно (`package.json`
  без `^`, `package-lock.json`); у кандидатов проверены peer-зависимости.
  TypeScript 7 не взят: `typescript-eslint` поддерживает версии ниже 6.1.
- Главная страница: назначение проекта, что можно спросить, три примера вопросов
  (вставляются в поле ввода, а не отправляются), пометки «студенческий проект, не
  официальный сервис», «ИИ может ошибаться» и предупреждение о личных данных.
- Чат: история с сервера, ввод (Enter / Shift+Enter, лимит длины), индикатор ожидания,
  четыре визуально разных состояния, блок источников.
  Пометки «Демо» (баннер и метка у ответов) сначала были, затем убраны по просьбе Эмиля.
  Тестовые ответы dev-mock сами сообщают, что ИИ не подключён.
- Переключатель RU / KZ; переведены все тексты интерфейса, ошибок и состояний.
  Выбор запоминается в браузере, меняется `<html lang>`.
- «Новый диалог» и «Удалить мои данные» с подтверждением.
- Повтор после ошибки с тем же `client_id`: на экране и на сервере остаётся один вопрос.
- PWA: манифест, иконки (свой логотип-компас, не символика организаторов), service worker
  кэширует только статику, `/api/*` не кэшируется. CSP в production-сборке.
- Корневые `.gitignore` (`.env`, `node_modules`, `dist`) и `.gitattributes` (LF).
- Документация: `frontend/README.md`; обновлены ARCHITECTURE.md (§4.4 API, §4.9, §4.11, §7, §9),
  AI_CONTRACT.md §8 (тестовые метки mock) и COMPETITION_REQUIREMENTS.md (состояния).

### Как запустить

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173. Тестовые метки для состояний (`#clarify`, `#noinfo`,
`#sources`, `#error`, `#flaky` и др.) описаны во `frontend/README.md`.

### Какие проверки выполнены

- `npm run typecheck`, `npm run lint` — без ошибок.
- `npm test` — 31 тест в 6 файлах прошли: словари RU/KZ, безопасный Markdown, источники,
  reducer повтора, API-клиент, сценарии App (главная, ожидание, уточнение,
  «нет информации» ≠ ошибка, повтор без дубликата, смена языка, новый диалог).
- `npm run build` — сборка проходит; в бандле нет кода dev-mock; в `sw.js` нет правил
  для `/api`, а `/api/*` исключён из навигационного fallback.
- Во встроенном браузере (dev-сервер с mock):
  - все состояния, источники с URL и без, безопасный Markdown (скрипт, `<b>`, картинка
    и `javascript:`-ссылка не сработали);
  - повтор `#flaky` (в истории сервера один вопрос), новый диалог, удаление данных
    (cookie недоступна из JS);
  - ширина 375 px на KZ без горизонтальной прокрутки;
  - светлая и тёмная темы.
- Production-сборка (`vite preview`): service worker активен, в кэше 12 файлов статики
  и ни одного `/api`, манифест и иконки на месте, запрос с CSP проходит,
  ошибок в консоли нет.

## Внешние настройки, которых пока нет

Значения задаются локально в `.env` или в настройках хостинга, в чат не отправляются.

- Ключ LLM-провайдера — переменная ИИ-модуля; имя сообщит ИИ-часть.
- Хостинг с HTTPS: нужен для демо, установки PWA и webhooks.
- PostgreSQL для демо (`DATABASE_URL`).
- Telegram: бот через @BotFather (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`).
- WhatsApp: Meta Business, приложение и номер — после решения по п. 4.7 условий Meta.
