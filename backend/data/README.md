# Подготовка базы знаний

Основная библиотека управляется через `/admin` и хранится в `library/`. Официальный каталог
скачивается кнопкой в панели либо `python -m app.collector`. Текст и оригинал доступны для просмотра;
только явно включённые после проверки документы участвуют в поиске. Папка исключена из Git.

Дополнительный рабочий корпус — `knowledge.jsonl`. Он намеренно не заполнен: неподтверждённые тексты
не должны становиться источниками ответов. Файл исключён из Git; публикуйте только тексты,
которые команда проверила и имеет право распространять. Тестовые вымышленные материалы находятся
в `tests/conftest.py` и в приложение не загружаются.

Каждая строка JSONL — отдельный JSON-объект с полями:

| Поле | Содержание |
|---|---|
| `id` | Уникальный ID фрагмента, например `doc1-ru-section1` |
| `document_id` | ID документа и языковой версии |
| `title` | Название из первоисточника |
| `section` | Статья/раздел, указанные в документе |
| `language` | `ru` или `kk` |
| `text` | Полный смысловой фрагмент: 30–9500 символов |
| `url` | HTTPS-ссылка на официальный первоисточник |
| `revision` | Проверенная редакция или дата публикации; не дата скачивания |
| `verified_at` | Дата фактической проверки источника в формате `YYYY-MM-DD` |

Сохраняйте условия и исключения вместе с правилом. Если нужный контекст превышает 9500 символов,
подготовьте связанные смысловые фрагменты вручную: механическое обрезание запрещено. Поиск не
гарантирует нахождение всех связанных положений, поэтому такие вопросы включаются в оценочный набор.
Не смешивайте редакции одного `document_id`. При обновлении закона пересматривайте все его фрагменты.
Сам по себе адрес официального сайта и заполненное поле `verified_at` не доказывают актуальность.

Русские и казахские источники загружаются отдельно. Для казахского ответа поиск использует казахский
текст; автоматический перевод русской цитаты не выдаётся за дословную казахскую цитату.

Валидация из каталога `backend`:

```bash
python -m app.corpus data/knowledge.jsonl
```

Команда проверяет структуру, дубликаты, разрешённые домены, смешение редакций и сроки проверки.
Она не устанавливает юридическую правильность источника. После изменения корпуса перезапустите
сервер. Через `SOURCE_MAX_AGE_DAYS` (по умолчанию 30) неперепроверенные фрагменты перестают участвовать
в ответах. Нельзя просто обновлять дату без проверки.

Официальные сайты для проверки и расширения каталога:

- [Әділет](https://adilet.zan.kz/) — нормативные документы и их редакции.
- [Акорда](https://www.akorda.kz/) — выступления, послания и инициативы.
- [gov.kz](https://www.gov.kz/) — официальные материалы государственных органов.

Конкурсное положение не является источником действующего права. Упоминание Конституции 2026 года
в положении само по себе не заменяет проверку её официального текста, статуса и даты действия.
