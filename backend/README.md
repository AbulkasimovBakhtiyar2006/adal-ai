# Backend Adal AI

Сервис на Python 3.11+ и FastAPI принимает вопрос на русском или казахском, ищет материалы
в подготовленном корпусе и показывает сгенерированный ответ только после трёх обязательных проверок.
Внешние интеграции: DeepSeek или Gemini для генерации, Google Cloud Check Grounding для проверки по источникам,
отдельная модель с совместимым Chat Completions API для критики (адрес по умолчанию — DeepSeek).

Реализован программный контур; для реальных ответов нужны проверенный корпус и доступы к API.
В приложении нет режима, который обходит проверки или подменяет их успешными результатами.
Автотесты используют вымышленные материалы и заглушки; они проверяют поведение кода, а не качество
внешних моделей. Пороговые значения экспериментальные, не показатели вероятности правильности.

## Запуск

Из корня репозитория:

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock
pip install --no-deps -e .
cp .env.example .env
python -m app
```

Если нужен другой установленный Python, используйте версию 3.11 или новее. На машине разработки
окружение `.venv` уже создано. Его содержимое не переносится через Git. Для переустановки зависимостей
без фиксированного набора версий можно использовать `pip install -e '.[dev]'`.

Сервер: `http://127.0.0.1:8000`. Управление: **`http://127.0.0.1:8000/admin`**.
Интерактивный контракт API: `http://127.0.0.1:8000/docs`.
Сервис запускается без ключей и корпуса, но `/ready` и запросы, требующие отсутствующих ресурсов,
сообщают о неготовности. Это не рабочий режим юридического консультирования.

Ключи и модели можно настроить на странице `/admin` без перезапуска. Альтернатива — `backend/.env`:

- `GENERATOR_PROVIDER=deepseek`, `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL` — генерация через DeepSeek.
- `GEMINI_API_KEY` и `GEMINI_MODEL` — ключ и ID доступной в вашем аккаунте модели с JSON Schema.
- `CRITIC_API_KEY`, `CRITIC_MODEL`, `CRITIC_BASE_URL` — отдельная модель-критик. Базовый URL не должен
  включать `/chat/completions`; для сервиса с префиксом `/v1` включите этот префикс в базовый URL.
  Если отдельный ключ не указан, для официального DeepSeek используется `DEEPSEEK_API_KEY`.
- `AUDIO_MODEL` — модель Gemini с поддержкой аудио; если пусто, используется `GEMINI_MODEL`.
- `GOOGLE_CLOUD_PROJECT` — проект Google Cloud с включённым Discovery Engine API, настроенным
  доступом и, когда это требуется сервисом, биллингом.
- `CORPUS_PATH` — проверенная база; относительный путь считается от `backend`, а не текущего каталога.

Google Check Grounding использует **Application Default Credentials**, а не ключ Gemini:

```bash
gcloud auth application-default login
gcloud auth application-default set-quota-project YOUR_PROJECT_ID
gcloud services enable discoveryengine.googleapis.com --project YOUR_PROJECT_ID
```

У учётной записи должно быть разрешение `discoveryengine.groundingConfigs.check`. В серверном
окружении используйте штатные credentials платформы либо `GOOGLE_APPLICATION_CREDENTIALS`
с путём к файлу вне репозитория. Не помещайте service-account JSON в корпус или клиентский код.
Получение credentials и реальные сетевые вызовы проверяются при запросе;
`/ready` проверяет только локальную конфигурацию, о чём прямо сообщает.

Бесплатный доступ к Gemini не означает бесплатный Google Cloud Check Grounding или DeepSeek.
Стоимость и доступность выбранных моделей проверяются в аккаунтах соответствующих сервисов.

## Страница управления и файлы

`/admin` обслуживается самим FastAPI, отдельный frontend-сервер не нужен. Три раздела:

- **Настройки ИИ** — ключи DeepSeek/Gemini, модели, проект Google, пороги и проверка доступа к списку моделей.
- **База знаний** — загрузка TXT/MD, DOCX, текстового PDF, HTML или вставка текста; просмотр извлечённого
  текста, скачивание оригинала, указание редакции и включение/исключение документа из поиска.
- **Проверка бота** — вопрос, результат каждого этапа, источники, аудиофайл или запись с микрофона.

Настройки сохраняются в `data/runtime/settings.json` с правами `0600` (каталог `0700`). Это локальный
файл с открытым текстом ключей, а не зашифрованный vault; он исключён из Git. API возвращает только
признак наличия ключа. Пустое поле сохраняет старый ключ; для удаления есть отдельная кнопка.
Сохранённые настройки имеют приоритет над `.env`. Изменение применяется сразу.

Без `ADMIN_API_KEY` API управления доступен только с loopback-адреса и hostname localhost/127.0.0.1/::1.
Для удалённого управления задайте отдельный `ADMIN_API_KEY`; он вводится при открытии страницы и
живёт только в памяти вкладки. `BACKEND_API_KEY` не открывает управление. Административные запросы
требуют `X-Adal-Admin: 1` и проверяются на тот же Origin. При размещении за прокси не оставляйте
административный ключ пустым: прокси может скрывать адрес внешнего клиента. Используйте HTTPS.

Максимум документа — 12 МБ, извлечённого текста — 2 млн символов. Сканы без текста отклоняются:
OCR пока не встроен. Таблицы сохраняются строками; сноски, порядок PDF и исправления DOCX нужно
проверить в просмотре. Слишком длинные абзацы отклоняются, а не обрезаются. Загруженный файл
не становится источником ответов автоматически. Для активации обязательны официальный URL,
название, проверенная редакция и отметка о просмотре. Индекс обновляется без перезапуска.

## Официальные источники

Кнопка «Скачать официальные источники» загружает фиксированный каталог из `app/catalog.py`.
То же из терминала в каталоге `backend`:

```bash
python -m app.collector
```

37 языковых версий из Әділет и Акорды: Конституция RU/KK; противодействие коррупции; доступ к
информации; административные процедуры; госслужба и госуслуги; общественные советы; правовые акты;
молодёжная политика; этический кодекс; концепции антикоррупционной и правовой политики, гражданского
общества и «Таза Қазақстан»; Национальный план до 2029 года; внутренняя политика; Курултай
2023/2024; послания 2024/2025. Это стартовый набор, а не исчерпывающая база всего законодательства.

Снимки находятся в `data/library/<id>/`: `original.bin`, `text.txt`, `record.json` с URL, временем
скачивания, SHA-256 и доступными метаданными официального API. Отчёт — `collection-report.json`.
Повторная загрузка одинакового текста не создаёт дубликат из-за меняющихся счётчиков страницы.
Изменившийся текст или статус источника требует нового просмотра. Старые снимки сохраняются.
Скачивание не подменяет проверку действующей редакции: документы сначала имеют статус «На проверке».
Официальный признак `is_actual=false` запрещает активацию. Файлы исключены из Git, каталог и загрузчик
воспроизводят набор на другой машине. Ошибки загрузки видны отдельно; доступные документы сохраняются.

## Аудио

`POST /api/audio/transcribe` принимает multipart-поле `file`, с тем же `Authorization`, что и `/api/ask`.
Форматы: WAV, MP3, OGG, FLAC, AAC, M4A, WebM; максимум 10 МБ и 3 минуты. Реальный формат и длительность
проверяются локально; видео отклоняется. Аудио отправляется Gemini и не сохраняется приложением.
Запись микрофона работает на localhost или HTTPS после разрешения браузера.

Ответ: `{"text":"…","language":"ru","duration_seconds":12.3,"review_required":true}`.
Интерфейс подставляет текст в редактируемое поле. После проверки человеком он отправляется в `/api/ask`
и проходит все три этапа. Токен DeepSeek не заменяет ключ Gemini для аудио. Без него возвращается
`503`; ошибочная запись — `422`. Реальное качество распознавания RU/KK требует проверки с ключом.

## Подключение фронтенда

```bash
curl http://127.0.0.1:8000/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"Что означает антикоррупционная культура?","language":"ru"}'
```

`language`: `ru`, `kk` или `auto` (по умолчанию). Автоопределение — простая эвристика; выбор языка
в интерфейсе надёжнее, особенно для коротких и смешанных вопросов. Максимум 2000 символов.
Сервис принимает отдельные вопросы; историю диалога и местоименные уточнения пока не обрабатывает.

| Поле ответа | Значение |
|---|---|
| `request_id` | ID для диагностики без записи текста вопроса |
| `status` | `answered`, `insufficient_evidence`, `temporarily_unavailable` |
| `answer` | Проверенный ответ либо статическое сообщение об отказе |
| `claims` | Только прошедшие все проверки утверждения с `evidence: [{source_id, quote}]` |
| `sources` | Названия, разделы, ссылки, редакции и даты проверки из локальной базы |
| `verification` | Результаты этапов, оценки Google, число попыток, коды причин |

`200` — ответ либо недостаточно подтверждений; `503` — отсутствует конфигурация или недоступен
обязательный внешний сервис; `422` — неверный запрос; `401` — неверный ключ; `429` — все слоты заняты.
При отказе `claims` пуст: непроверенный текст не попадает в ответ, ошибки или журналы приложения.
Источники при отказе — найденные материалы для самостоятельного чтения, а не доказательство ответа.
Отрисовывайте строки как текст, без небезопасной вставки HTML. Ссылки берите только из `sources`.
Не подписывайте оценки Google как «процент достоверности».

## Как устроена проверка

```text
Вопрос → выбор языка → BM25 по свежим фрагментам этого языка
  → DeepSeek/Gemini возвращает короткие утверждения и точные цитаты в JSON
  → код проверяет структуру, ID, цитаты, числа и запрет сгенерированных ссылок
  → Google Check Grounding проверяет весь текст и каждое утверждение
  → отдельный критик проверяет ответ по вопросу, условиям и исключениям
  → код выпускает ответ только при прохождении всех этапов
```

Поиск использует BM25 с положительным IDF, русскую основу слов Snowball и небольшой словарь
русских/казахских выражений. Казахского морфологического анализатора и поиска по эмбеддингам пока нет.
Слабая релевантность поиска должна приводить к отказу генератора/критика; ранжирование не доказывает
применимость документа. В контекст входят целые фрагменты, до пяти и до 30 000 символов суммарно.

Google получает исходные фрагменты и окончательный текст без добавочных вступлений. Включена
проверка отдельных утверждений. Код требует полного покрытия ответа проверенными диапазонами
UTF-8, достаточно высоких оценок каждого утверждения, реальных цитат и соответствия источникам,
на которые ссылается генератор. Высокий общий балл не компенсирует неподтверждённую фразу.
Параметр Google `citationThreshold` отвечает за подбор цитат; пороги допуска ответа проверяются
нашим кодом отдельно. Ответы Google без ожидаемых полей отклоняются.

Критик получает вопрос, ответ и документы, но не баллы Google. Он обязан проверить каждое
утверждение ровно один раз и объяснить вердикт. Код проверяет полноту отчёта и идентификаторы.
Его объяснения не публикуются пользователю и не используются как новый источник истины.
Использование другой модели не делает её ошибки статистически независимыми.

После отрицательного результата допускается ровно одна новая генерация с кодами ошибок.
Новый ответ проходит все этапы заново. При недоступности внешнего сервиса повторная генерация
не запускается: возвращается `temporarily_unavailable`. Общий лимит времени — 100 секунд,
лимит одного HTTP-запроса — 25 секунд, максимум четыре активных запроса. Потоковая выдача отключена.

## Проверка качества

```bash
pytest -q
ruff check app tests
python -m app.corpus data/knowledge.jsonl
```

Тесты проверяют успешную цепочку RU/KK, выдуманные ссылки, искажённые цитаты, неподтверждённые числа,
пропущенные утверждения, Unicode-диапазоны, отказ критика, тайм-ауты, сетевые ошибки, повторную проверку,
конкурентные запросы, отсутствие утечек отклонённого текста и HTTP-контракты адаптеров.

Перед демонстрацией с реальными API:

1. Подготовьте и проверьте корпус по инструкции `data/README.md`.
2. Соберите отдельные RU/KK наборы вопросов: ожидаемые источники, допустимые ответы и необходимые
   отказы. Включите числа, отрицания, исключения, устаревшие редакции, нерелевантные вопросы,
   инструкции внутри документов и эмоциональные вопросы с руганью.
3. Проверьте фактические ответы человеком. Измеряйте ошибки среди показанных ответов и долю отказов.
   Наличие цитаты и успешные автоматические проверки сами по себе не являются эталонной разметкой.
4. Настройте пороги на одной части набора и оцените результат на другой. Качество русского
   проверяющего нельзя переносить на казахский без отдельной оценки.

Сервис не обещает отсутствие ошибок. Актуальность права, полнота корпуса и качество объяснений
нуждаются в содержательной проверке. Требования конкурса шире антикоррупционных вопросов;
полноценный конкурсный корпус ещё нужно проверить и расширить. Внешние AI API без ключей
не тестировались; загрузчик официальных документов проверен реальными скачиваниями.

## Размещение

Запуск по умолчанию только на localhost. Для `HOST=0.0.0.0` приложение требует `BACKEND_API_KEY`;
в запросах передавайте `Authorization: Bearer ...`. Это ключ для доверенного сервера/Telegram-бота,
не секрет для встраивания в общедоступный браузерный JavaScript. Для публичного фронтенда нужен
серверный посредник или полноценная пользовательская авторизация. Настройте HTTPS, ограничение
частоты и размера запросов на прокси. Ограничение параллельности действует на один процесс.
CORS разрешает только явно перечисленные origins; это не механизм авторизации.
Не передавайте чувствительные персональные сведения во внешние модели без соответствующего
основания: вопрос и найденные тексты отправляются генератору и критику, ответ и фрагменты — Google.

## Файлы и документация API

- `app/retrieval.py` — поиск и выбор языка.
- `app/providers.py`, `app/prompts.py` — внешние API и инструкции моделям.
- `app/verification.py` — правила допуска ответа.
- `app/service.py` — порядок этапов и единственная повторная попытка.
- `app/main.py` — HTTP API, доступ, диагностика и ограничение параллельности.
- `app/corpus.py` — проверка локальной базы.
- `app/admin.py`, `app/static/` — серверная страница управления и её API.
- `app/storage.py` — хранение настроек; `app/library.py` — библиотека и активация.
- `app/parsing.py`, `app/collector.py`, `app/catalog.py` — извлечение текста и официальный каталог.
- `app/audio.py` — проверка аудио и расшифровка.

Официальные контракты, использованные при реализации:
[Gemini structured output](https://ai.google.dev/gemini-api/docs/generate-content/structured-output),
[Google Check Grounding REST](https://docs.cloud.google.com/generative-ai-app-builder/docs/reference/rest/v1/projects.locations.groundingConfigs/check),
[DeepSeek JSON mode](https://api-docs.deepseek.com/guides/json_mode/).
Распознавание: [Gemini audio](https://ai.google.dev/gemini-api/docs/audio).
