# Adal AI — пять референсов для редизайна

Дата просмотра: 16 октября 2026. PNG — реальные снимки первых экранов сайтов в браузере, не макеты будущего Adal AI. Выбор направления пока не сделан. Код приложения на этом этапе не менялся.

Пожелание: масштабный портал в стилистике государственных сайтов с удобством ИИ-чата. Уйти от ощущения слишком простого шаблонного ИИ-сайта. Пользователь сначала выбирает один из пяти референсов, затем начинается редизайн.

1. **GOV.KZ** — https://www.gov.kz/?lang=ru
   Скриншот: `01-gov-kz.png`.
   Широкий первый экран, крупный заголовок и поиск, тематические вкладки, фотографии, много разделов ниже.
   Для Adal AI: большая главная, разделы документов и тем, навигация по базе знаний, отдельный вход в ИИ-чат. Объёмные декоративные иллюстрации необязательно переносить.
2. **eGov Казахстан** — https://egov.kz/ru
   Скриншот: `02-egov.png`.
   Постоянное левое меню, фотография архитектуры в первом экране, поиск в центре, плотная сетка сервисов.
   Для Adal AI: меню «Главная / ИИ-консультант / Документы / История», фотография Казахстана, каталог тем и заметные действия. Рекомендуемая основа по сочетанию портала и приложения.
3. **GOV.UK** — https://www.gov.uk/
   Скриншот: `03-gov-uk.png`.
   Синий первый экран, большая типографика, контрастный поиск, списки ссылок и тематические разделы.
   Для Adal AI: строгая иерархия, удобное чтение документов и ответов, минимум украшений. Более сдержанное визуальное направление.
4. **LifeSG** — https://www.life.gov.sg/
   Скриншот: `04-lifesg.png`.
   Верхнее меню, тёплый светлый фон, центральный поиск, быстрые темы и иллюстрации жизненных ситуаций.
   Для Adal AI: современный общественный портал с понятными сценариями. Дружелюбнее и мягче, чем классический ведомственный стиль.
5. **ChatGPT** — https://chatgpt.com/
   Скриншот: `05-chatgpt.png` (публичный экран без входа, тёмная тема).
   Боковое меню, просторное поле разговора, компактная строка ввода и микрофон.
   Для Adal AI: устройство экрана чата, история и голосовой ввод. Как единственная основа главной может сохранить ощущение слишком простого ИИ-сайта.

Предложение: визуальная основа №2 eGov, логика экрана разговора №5 ChatGPT. Сохранить собственный бренд Adal AI и существующую функциональность чатов, истории, RU/KZ и звонка. После выбора переработать композицию, навигацию, типографику, палитру, главную, экран чата и мобильный вид; не ограничиваться сменой цвета.
